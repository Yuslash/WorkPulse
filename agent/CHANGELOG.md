# WorkPulse Agent Changelog

All notable changes to the WorkPulse Agent will be documented in this file.

## [1.0.1] - 2026-08-26
### Added
- Added interactive global installation and Shift Selection prompt on startup.
- Telemetry gathering now pauses when outside the selected shift boundaries.

## [1.0.0] - Initial Release
### Added
- Transparent activity telemetry collection (foreground app, idle time).
- Secure Dpapi identity storage.
- Auto-start Windows Service and Logon Task registration.
